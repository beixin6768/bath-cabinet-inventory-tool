1️⃣ 我做出的小工具：浴櫃庫存管理

當初的痛點：一組浴櫃 ＝ 一個主櫃 ＋ 一個鏡櫃/鏡子。出貨時要分別扣兩種庫存，常常無法馬上知道正確庫存量、還能出幾整組。
解法：一頁 HTML（浴櫃庫存小工具.html），點兩下就能用，不用安裝任何東西。
功能總覽：
  • 出貨「浴櫃組」→ 自動同時扣 主櫃 + 鏡櫃
  • 單買主櫃、單買鏡櫃也能記
  • 即時庫存表：可出貨組數 = min(主櫃, 鏡櫃)
  • 庫存不足自動警告擋下
  • 出貨/進貨歷程，可單筆刪除復原
  • 資料自動保存在瀏覽器（localStorage）
  • 「4. 批次輸入」從 Excel 貼上一鍵套用真實庫存
  • ⬇ 匯出備份 / ⬆ 匯入備份（換電腦用）
  • 產品清單＝公司真實 49 個系列×尺寸

2️⃣ 每天怎麼用（3 步）

  1. 雙擊桌面的 浴櫃庫存小工具.html（用自己電腦的瀏覽器開，Edge 或 Chrome 都可以）
  2. 看最上面的狀態字：
    🟢「✔ 已載入上次保存的庫存資料」＝數字都在，開始用
    🔴「⚠ 沒有找到保存的資料」＝這次開的方式讀不到（見第 4 節解法）
  3. 記錄出貨：選系列 → 尺寸 → 類型 → 數量 → 「＋ 記錄這筆」。庫存表會自動扣！

3️⃣ 批次輸入真實庫存（從 Excel）

格式：每一行 系列 尺寸 主櫃數 鏡櫃數（空白、逗號、Tab 都可以隔開）

初綻 60 8 6
初綻 80 3 5
盛放 100 10 4

從 Excel 複製的訣竅：只框「資料列」、不要選標題列（系列/尺寸/主櫃/鏡櫃那行文字），貼進「4. 批次輸入」按「✔ 一鍵套用」。

※ 批次輸入是「直接設定庫存」，不會留進貨紀錄。想留紀錄就用上面的「進貨」。

4️⃣ 資料保存與搬家（最重要的一節）

核心觀念：庫存數字存在「瀏覽器」裡，不會跟著 HTML 檔案走。 換瀏覽器（Edge↔Chrome）、換電腦、用別的方式開（例如 AI 助手的預覽視窗）→ 都會讀不到，顯示預設值 5。
解法＝備份檔：按「⬇ 匯出備份」→ 存下 浴櫃庫存備份_日期.json。
新電腦：雙擊開 HTML → 按「⬆ 匯入備份」→ 選 json 檔 → 數字全部回來。
換電腦標準流程：
  1. 舊電腦：匯出備份（json）
  2. 帶 2 個檔案：HTML（工具本體）＋ json（備份）。隨身碟 / LINE 傳自己 / Email 都行
  3. 新電腦：開 HTML → 匯入 json → 完成
習慣建議：每週（或每次大改庫存後）匯出一次備份，檔案越新越保險。

6️⃣ Mermaid 流程圖（第⑥關必備）

一句話：用打字的方式畫流程圖——改圖＝改文字，存得下來、交接得出去。
語法速查表：
寫法意思畫出來
flowchart TD流程圖，上到下（LR＝左到右）整張圖方向
A[做事]A 點，名叫「做事」方框
C{要判斷?}有問題要判斷菱形
-->箭頭→
-->|有|箭頭上寫字（次數/時間/條件）→有→
[[人確認]]必須由人把關的一步雙線框
subgraph 人做 ... end把一組框在一起分區塊
老師第⑥關的 5 條規則：
  1. 用 flowchart TD，由上到下
  2. 一個方框只寫一件事，八個字以內
  3. 用 subgraph 分開「人做」跟「AI 做」
  4. 次數、時間寫在線上，例如 A -->|每週三次| B
  5. 人要確認的那一步，用雙框 [[人確認]]
檢查重點：對外承諾那一步，有雙框嗎？沒有就叫 AI 改。
練習範例（我的浴櫃出貨「現況」）： 
flowchart TD
  A[客戶訂浴櫃] --> B[打開Excel庫存表]
  B --> C[查主櫃庫存]
  C --> D[查鏡櫃庫存]
  D --> E[心算扣庫存]
  E --> F{庫存夠嗎?}
  F -->|夠| G[出貨改Excel]
  F -->|不夠| H[回覆客戶等貨]
  G --> I[[老闆確認數量]]

在哪裡畫：① mermaid.live（貼上就出圖，可下載 PNG）② Notion 打 /code → 語言選 Mermaid

※ 還差一張「導入後」：用 subgraph 分「人做 / AI 做」，跟「現況」湊成對照組。

7️⃣ 疑難雜症記錄（遇到就知道怎麼辦）

❓ 庫存數字突然回到預設值 5
原因：用了不同的「開啟方式」（預覽視窗、換瀏覽器、不同電腦），瀏覽器讀不到原本的資料。
解法：用平常的方式重開一次；或按「⬆ 匯入備份」把 json 救回來。
❓ Incorrect API key provided（金鑰錯誤）
API key 像一把鑰匙，這訊息＝鑰匙被擋下。常見原因：
  1. 複製時多空格或少字元（最常見）
  2. 舊金鑰已被刪除或重新產生
  3. 拿 A 服務的金鑰去用 B 服務
  4. 拿「網頁登入 token」當 API key 用
  5. 設定沒生效（貼錯欄位/沒存）
  6. 帳號沒開通或沒綁付款
解法 3 步：重新產生新 key → 完整複製（注意開頭結尾沒空格）→ 確認服務選對。
※「Free usage limit reached」＝免費額度用完，不是金鑰錯誤，等額度恢復或升級方案。

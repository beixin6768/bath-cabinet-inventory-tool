# 浴櫃庫存小工具 🛁

AI 課程（金屬中心 MIRDC 第二梯）的期末小工具。

## 這是什麼
一頁 HTML，點兩下就能用。解決的痛點：

> 一組浴櫃 = 一個主櫃 + 一個鏡櫃/鏡子。出貨時要分別扣兩種庫存，
> 常常無法馬上知道正確庫存量、還能出幾整組。

## 功能
- 出貨「浴櫃組」時，自動同時扣掉主櫃與鏡櫃庫存
- 支援單買主櫃、單買鏡櫃/鏡子
- 即時顯示每個型號的主櫃/鏡櫃庫存與「可出貨組數」= min(主櫃, 鏡櫃)
- 庫存不足時擋下並警告
- 出貨/進貨歷程記錄，可單筆刪除復原
- 資料自動保存在瀏覽器（localStorage），關掉不消失
- 批次輸入：從 Excel 複製「系列 尺寸 主櫃數 鏡櫃數」直接貼上一鍵套用

## 怎麼用
1. 下載 `浴櫃庫存小工具.html`
2. 點兩下用瀏覽器打開（不需要安裝任何東西）
3. 在「4. 批次輸入真實庫存」貼上自己的庫存清單，開始使用

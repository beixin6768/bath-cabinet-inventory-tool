浴櫃庫存小工具

一頁 HTML，點兩下就能用的庫存管理工具

AI 課程（金屬中心 MIRDC 第二梯）期末小工具

痛點：為什麼需要它？

  • 一組浴櫃 = 一個主櫃 + 一個鏡櫃/鏡子
  • 出貨時要分別扣兩種庫存
  • 常常無法馬上知道「正確庫存量」與「還能出幾整組」
  • 手動計算容易出錯、庫存對不起來

解決方案

輸入「出貨幾組」，系統自動同時扣掉主櫃與鏡櫃庫存，即時顯示每個型號的可出貨組數。

核心功能

  • 浴櫃組出貨：自動同時扣主櫃 + 鏡櫃
  • 支援單買主櫃、單買鏡櫃/鏡子
  • 即時顯示主櫃/鏡櫃庫存與「可出貨組數」
  • 庫存不足時擋下並警告
  • 出貨 / 進貨歷程記錄，可單筆刪除復原
  • 批次輸入：從 Excel 複製後一鍵套用真實庫存
  • 匯出 / 匯入 JSON 備份

使用流程

  • 1. 選產品：系列 → 尺寸 → 類型（浴櫃組 / 主櫃 / 鏡櫃）
  • 2. 輸入數量：出貨或進貨、日期、數量
  • 3. 查看庫存：主櫃、鏡櫃、可出貨組數、狀態
  • 4. 批次輸入：貼上「系列 尺寸 主櫃數 鏡櫃數」一鍵套用

批次輸入範例

每行一個型號，空白或逗號分隔：

初綻 60 8 6 初綻 80 3 5 盛放 100 10 4 雅境 60 6 6

✅ 一鍵取代整天設定值，不用一筆一筆輸入

資料保存與備份

  • 資料自動存在瀏覽器（localStorage）
  • 關掉網頁、重新開啟都不會消失
  • 「匯出備份」下載 JSON 檔
  • 「匯入備份」還原庫存與紀錄
  • 「重設」可清空所有資料

技術與擴充

  • 單一 HTML 檔，無需安裝、無後端
  • 純前端：HTML / CSS / JavaScript
  • 產品資料內建（40+ 系列 × 多尺寸）
  • 新增系列只需在程式中加一行
  • 可延伸：多使用者、雲端同步、報表輸出
